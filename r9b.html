깃허브(GitHub)로 내 앱 배포하기

제미나이로 만든 앱을 index.html로 저장해 깃허브에 올리고, 내 고정 주소를 만들어 폰·PC에 앱으로 설치합니다.

깃허브 Pages · 가입은 전날 집에서 · 막히면 플랜 B(선생님 시연) · 🟦 청양은 STEP 7까지, 🟩 홍성은 끝까지(구분은 매튜 제안)

⚠️ 수업 당일 확인 (강사가 먼저 봅니다)

  • 깃허브 가입은 수강생이 직접 합니다. 교실 와이파이에서 여럿이 동시에 가입하면 정지될 수 있으니 전날 집에서 각자 가입+인증을 하고, 당일엔 로그인만 합니다.
  • 깃허브 화면·메뉴 이름(새로운 저장소, 설정, 페이지 등)은 바뀔 수 있고, Pages의 무료 조건과 공개 범위는 이 사이트에서 확인하지 못했습니다. 수업 당일 확인합니다. 화면이 다르면 강사에게 물어보세요.
  • 공개(Public) 저장소는 누구나 볼 수 있습니다. 이름·전화번호·주소·계정 정보·수진자 자료는 올리지 않습니다. 삭제는 되돌릴 수 없고, 비밀번호·인증코드·이메일은 어디에도 적거나 알려 주지 않습니다.
  • 막히면 플랜 B: 선생님이 직접 시연·대신 배포해 주소와 QR을 공유합니다. 배포가 안 돼도 만들기만으로 충분합니다.
  • 비교표(넷리파이 vs 깃허브)와 시연 앱은 9회차 ③ ④ 페이지에 있습니다. 수업의 기본 배포는 이 페이지의 깃허브입니다.

[내 사용자이름].github.io/[저장소이름]/ 모양의 인터넷 주소

②
고쳐도 같은 주소로 갱신 + 앱 설치

🟩 홍성: 수정·앱 설치까지 / 🟦 청양: 주소 확인까지

집에서 다시 해 보려면

  1. 9회차에서 만든 앱의 코드를 메모장에 붙여넣어 index.html로 저장합니다. (끝이 .txt가 아닌지 확인)
  2. 깃허브에 로그인하고 저장소(Public)를 만듭니다. 이름은 영문 소문자·숫자·하이픈.
  3. "기존 파일을 업로드하여"로 index.html을 올리고 초록 "변경 사항을 커밋합니다"를 누릅니다.
  4. Settings → Pages에서 Deploy from a branch, main, / (root)를 저장하고 1~2분 뒤 주소를 확인합니다.
  5. 주소를 카톡 나에게 보내 폰에서 열어 보고, 고치고 싶으면 같은 이름으로 다시 올립니다.

이 페이지 쓰는 법

  1. 수업 중에는 폰이나 컴퓨터에 이 페이지를 열어 두세요.
  2. 각 칸의 누르기 → 쓰기 → 성공 순서로 한 칸씩만 하세요. 끝낸 칸은 "이 단계 했어요"에 체크하면 다음에 열어도 표시가 남습니다.
  3. 검은 상자는 [복사하기]를 누른 뒤 채팅칸에 붙여넣고, 대괄호 [ ] 안만 내 것으로 바꾸세요.
  4. 막히면 🆘 막혔을 때를 눌러 보세요. 화면이 다르면 손을 들어 강사에게 물어보세요.

시작 전에 · 큰 그림, 비교, 안전 약속

이 페이지는 9회차에서 제미나이 캔버스로 만든 앱을 내 고정 주소로 인터넷에 올리는 방법(깃허브 Pages)을 알려 드립니다. 배포란 내 컴퓨터에만 있던 작업물(HTML 앱)을 "인터넷 주소"로 만들어 누구나 열게 하는 것입니다.

🔗 오늘 쓰는 사이트
🔗 깃허브(GitHub) 열기 github.com
🔗 제미나이(Gemini) 열기 gemini.google.com

① 오늘의 흐름 — 만들기 → 빠른 공유 → 고정 주소 → 앱 설치

  1. 만들기 — 제미나이 캔버스로 앱(HTML) 만들기

    보기9회차 3교시에서 한 일입니다. 여기서는 배포에 필요한 부분만 다시 짚습니다.

  2. 빠른 공유 — 캔버스·제미나이 공유 링크

    보기배포 없이 링크로 바로 나눌 수 있지만 제미나이 안에서 열리고, 앱으로 설치는 안 돼요. 보는 사람이 로그인해야 할 수 있습니다. (9회차에서 했어요)

  3. 고정 주소 — 깃허브에 올려 내 주소 만들기

    보기index.html 저장 → 깃허브 가입 → 저장소 → 업로드(커밋) → Pages 켜기 → 주소 확인

  4. 앱 설치 — 폰·PC에 앱으로 등록

    성공주소가 고정이라 한 번 알려 주면 끝이고, 고쳐도 같은 주소가 갱신됩니다.

② 빠른 공유 vs 깃허브 배포 — 무엇이 다른가요?

  • 빠른 공유(캔버스·제미나이 공유 링크) — 배포 단계가 없어 빠릅니다. 제미나이 안에서 열리고 앱 설치는 안 됩니다. 로그인이 필요할 수 있고, 고쳐도 이미 보낸 링크는 옛 모습이라는 점은 9회차에서 했어요.
  • 깃허브 배포(Pages) — 주소가 고정이고, 파일을 고쳐 다시 올리면(커밋) 같은 주소가 갱신되며, 무료이고, 공개 주소라서 폰·PC에 앱으로 설치할 수 있습니다. 여러 번 고쳐 쓸 자료에 알맞습니다.
📎 위 비교는 강의 자료(깃허브 배포 완전 가이드)에 적힌 내용입니다. 깃허브 Pages의 무료 조건과 공개 범위, 메뉴 이름은 바뀔 수 있어 수업 당일 확인합니다.

넷리파이와의 비교: 자료에는 "빠르게 한 장 올리기는 넷리파이, 코드 관리·협업은 깃허브"로 되어 있습니다. 수업에서는 깃허브로 합니다. 비교표와 넷리파이 따라하기는 선택 코너에 있어요.

➡ 9회차 ③ 넷리파이로 배포하기 (다른 방법·선택, 비교표)

AI 챗봇(제미나이 Gem·챗GPT GPTs·클로드)을 링크로 공유하는 방법은 6·7회차에서 했어요. 이 페이지는 내가 만든 웹페이지(HTML)를 올리는 방법입니다.

③ 어려운 말, 쉬운 비유로

📖 어려운 말 풀이

저장소(Repository)
내 파일을 넣어 두는 "인터넷 서랍장". 이름이 나중에 주소에 쓰입니다.
커밋(Commit)
"이 변경을 저장·기록한다"는 도장. 초록 버튼을 눌러야 실제로 올라갑니다.
Pages(페이지)
서랍장 안의 파일을 "웹사이트로 띄워 주는 스위치". 이 스위치를 켜야 인터넷 주소가 생깁니다. (진짜 배포)
Public(공공의·공개)
누구나 볼 수 있는 "공개 게시판". Pages 무료는 Public으로 한다고 가이드에 적혀 있습니다.
브랜치(main)
서랍장의 "원본 줄기"의 이름. 우리는 main을 고르기만 하면 됩니다.
사용자이름(Username)
내 깃허브 이름. 주소에 들어갑니다. 영문·숫자로 짧고 깔끔하게.
index.html
웹사이트의 "첫 화면 이름표". 이 이름이어야 첫 화면으로 열립니다.

④ 안전 약속 — 꼭 읽으세요

  1. 가입·로그인은 내가 직접 합니다

    보기이 사이트는 대신 가입하거나 로그인하지 않습니다. 비밀번호·인증코드·이메일은 다른 사람에게 알려 주지 말고 어디에도 적어 두지 마세요.

  2. 공개(Public) 저장소는 누구나 볼 수 있어요

    보기개인정보(이름·전화번호·주소·계정 정보·수진자 자료)는 올리지 않습니다. 올릴 파일을 먼저 열어 보고 개인정보가 없는지 확인하세요.

  3. 삭제는 되돌릴 수 없어요

    보기지우고 싶지 않다면 "삭제" 대신 "보관(Archive)"을 쓰세요(읽기 전용으로 얼려 두기).

  4. 교실에서 한꺼번에 가입하면 정지될 수 있어요

    보기같은 와이파이에서 여러 명이 동시에 가입하면 봇으로 오인돼 정지될 수 있다고 가이드에 적혀 있습니다.

    성공그래서 전날 집에서 각자 가입+인증을 마치고, 수업 당일에는 로그인만 합니다.

⑤ 🅱️ 플랜 B — 막혀도 괜찮아요 (🟦 청양 어르신께 특히)

✅ 꼭 기억하세요배포가 안 돼도 "만들기"만으로 충분합니다. 가입·인증이 가장 큰 벽이므로, 막히면 선생님이 직접 시연하고 대신 배포해서 주소와 QR을 나눠 드립니다. 배포는 집에서 천천히 하세요.

⑥ 청양 / 홍성 — 이 페이지를 쓰는 방법 (구분은 매튜 제안)

  • 🟦 청양(어르신) — 가입·인증은 전날 집에서, 당일엔 로그인만. STEP 1~7(앱 만들기 → 주소 확인)까지 하고, 막히면 플랜 B. 수정·삭제·앱 설치는 구경해도 충분합니다.
  • 🟩 홍성(강사) — STEP 8(수정·삭제)과 STEP 9(앱 설치), 고정 주소를 소개·제안서·QR에 활용하는 것까지 직접 해 봅니다.

※ 위 청양/홍성 구분은 원본에 없어 매튜가 제안한 것입니다. 원본에 있는 것은 "전날 집에서 가입", "플랜 B"입니다.

🆘 막혔을 때 (눌러서 펼치세요)
❓ 가입이 겁나요

→ 전날 집에서 각자 천천히 하세요. 가입과 인증만 끝내 두면 수업 당일에는 로그인만 하면 됩니다. 어려우면 가족이나 선생님께 옆에서 봐 달라고 하세요. 비밀번호·인증코드는 말하지 마세요.

❓ 깃허브가 뭔지 모르겠어요

→ "내 파일을 넣는 인터넷 서랍장"이고, 그 서랍장의 파일을 웹사이트로 띄워 주는 기능이 Pages입니다.

❓ 꼭 배포를 해야 하나요?

→ 아니요. 오늘은 만들기만으로 충분합니다. 배포는 집에서 천천히 하세요.

  • 언제 쓰나요? 배포할 내 앱(HTML 한 파일)을 새로 만들 때

STEP 2 · 폴더에 index.html 저장하기 ★

가장 많이 틀리는 곳입니다. 파일 이름이 index.html(영문 소문자)이어야 깃허브가 "첫 화면"으로 알아봅니다.

  1. 내 컴퓨터에 새 폴더를 하나 만드세요

    쓰기폴더 이름 예: my-app

    성공바탕화면에 폴더가 하나 생기면 성공입니다.

  2. 메모장을 열고 복사한 코드를 붙여넣으세요

    누르기메모장(또는 VS Code)을 열어 붙여넣기(Ctrl+V)를 하세요.

    성공긴 글자(코드)가 메모장에 들어가 있으면 성공입니다.

  3. "다른 이름으로 저장"을 누르세요

    누르기메모장 메뉴 → 파일 → 다른 이름으로 저장.

    보기저장 위치는 방금 만든 폴더입니다.

  4. 파일 이름에 index.html 을 쓰고, 파일 형식을 "모든 파일"로 하세요

    쓰기아래 복사 상자의 이름을 그대로 쓰세요. 영문 소문자입니다.

    보기파일 형식을 "텍스트 문서"로 두면 index.html.txt가 되어 안 열립니다.

    성공폴더 안에 index.html 파일이 보이고, 이름 끝이 .txt가 아니면 성공입니다.

  • 바꿀 곳 바꿀 곳은 없습니다. 소문자 index.html 그대로 쓰세요. 한글 "인덱스.html"이나 index.html.txt는 안 됩니다.

❓ 파일 이름이 한글로 됐어요

❓ 더블클릭하니 글자만 나와요

→ 시작 메뉴에서 "메모장"을 찾아보세요. 못 찾으면 강사에게 물어보세요.

STEP 4 · 저장소(Repository) 만들기

로그인한 뒤, 내 "인터넷 서랍장"을 하나 만듭니다. 실제 화면 순서 그대로 따라오세요.

  1. 오른쪽 위 ＋를 누르고 "새로운 저장소(New repository)"를 고르세요

    누르기※ 메뉴 이름이 다르면 강사에게 물어보세요.

  2. 소유자가 내 계정인지 확인하세요

    보기"소유자(Owner)" 칸에 내 사용자이름이 보여야 합니다.

  3. 저장소 이름을 쓰세요

    쓰기영문 소문자·숫자·하이픈만. 한글·공백은 안 됩니다. 예: my-app

    성공아래에 초록 "✓ 사용할 수 있습니다"가 뜨면 성공입니다.

  4. 설명(선택)은 써도 되고 안 써도 돼요

    쓰기예: 약 체크리스트 웹앱처럼 용도 메모

  5. "표시 여부"를 "공공의(Public)"로 두세요

    보기Pages 무료는 Public으로 해야 한다고 가이드에 있습니다. 누구나 볼 수 있으니 민감한 정보는 올리지 마세요. (Pages 무료 조건은 수업 당일 확인)

  6. README·.gitignore·라이선스는 그대로 두고 맨 아래 초록 "저장소 생성"을 누르세요

    보기다른 강의 자료에는 "Add a README에 체크하고 Create"라고도 적혀 있습니다. 어느 쪽이든 index.html을 올리는 데는 문제가 없고, 당일 강사 안내를 따르세요.

    성공"빠른 설정" 화면이 나오면 저장소가 만들어진 것입니다.

STEP 8 · 수정(업데이트)과 삭제 (🟩 홍성 직접 해 보기 / 🟦 청양은 구경)

"업데이트"라는 단추는 따로 없습니다. 깃허브에서는 파일을 고쳐서 다시 커밋하는 것이 곧 업데이트입니다.

① 수정하기

  • 목록에 보이는 "업데이트됨 O월 O일"은 단추가 아니라 마지막으로 바뀐 날짜 표시입니다.
  • 커밋만 하면 같은 주소가 자동으로 갱신됩니다. (새 주소가 생기지 않습니다.)

  1. 방법 A — 직접 고치기

    누르기파일(index.html)을 누르고 연필(✏️) 아이콘 → 내용 수정 → "변경 사항을 커밋합니다".

    성공1~2분 뒤 같은 주소로 열면 고친 모습이 보이면 성공입니다.

  2. 방법 B — 통째로 교체하기

    누르기"파일 추가(Add file) → 파일 업로드"로 같은 이름(index.html)의 새 파일을 올려 덮어쓰고 커밋하세요.

    보기캔버스에서 앱을 고쳤다면 코드를 다시 복사해 index.html을 새로 저장한 뒤 이 방법을 쓰면 됩니다.

② 삭제 — "위험 지역(Danger Zone)"

설정(Settings) 맨 아래로 내려가면 "위험 지역"이 있습니다. 항목별 뜻:

  • 변경 저장소 가시성 — 공개 ↔ 비공개 전환 (지금은 "공개").
  • 분기 보호 규칙 비활성화 — 고급 기능이라 초보는 무시하세요.
  • 소유권 이전 — 이 저장소를 다른 사람·조직에 넘기기.
  • 이 저장소를 보관하세요 — 읽기 전용 보관(Archive). 삭제가 아니라 "얼려 두기"입니다.
  • 이 저장소를 삭제하세요 — 완전 삭제.
✅ 지우기 전에"안 쓰지만 혹시 몰라 남기고 싶다"면 삭제 말고 "보관(Archive)"을 쓰세요. 읽기 전용으로 얼려 두며 주소는 유지됩니다.

  1. 위험 지역의 "이 저장소를 삭제하세요" 단추를 누르세요

    보기⚠️ 되돌릴 수 없어요! 저장소 안의 모든 파일·기록이 사라지고, Pages 주소도 바로 열리지 않습니다. 정말 지울 것만, 꼭 확인하고!

  2. 경고창이 뜨면 저장소 이름을 똑같이 직접 입력하세요

    쓰기[내 사용자이름]/[저장소이름] 모양입니다. 일부러 직접 치게 한 것은 실수로 못 지우게 한 안전장치입니다.

  3. 최종 확인 단추를 눌러야 삭제됩니다

    성공삭제하지 않으려면 여기서 멈추고 창을 닫으세요.

  2. 💻 PC(크롬): 내 주소를 열고 주소창 끝의 설치 아이콘(⊕)을 누르세요

    성공바탕화면이나 시작 메뉴에 앱이 생기면 성공입니다.

  3. 💻 PC(엣지): ⋮ → 앱 → "이 사이트를 앱으로 설치"

⚠️ 공개(Public) 저장소는 누구나 볼 수 있어요

개인정보(이름·전화번호·주소·계정 정보·수진자 자료)는 올리지 않습니다. 올리기 전에 파일을 열어 확인하세요.

⚠️ 가입·로그인은 내가 직접

이 사이트는 대신 가입하거나 로그인하지 않습니다. 비밀번호·인증코드·이메일은 다른 사람에게 알려 주거나 적어 두지 마세요. 교실 동시 가입은 정지될 수 있으니 전날 집에서 각자 하세요.

⚠️ 삭제는 되돌릴 수 없어요

정말 지울 것만 지우세요. 남기고 싶다면 "보관(Archive)"을 쓰세요.

⚠️ 파일 이름이 가장 중요해요

영문 소문자 index.html. 한글 "인덱스.html"이나 index.html.txt는 첫 화면이 안 열립니다(404).

⚠️ 화면·무료 조건은 바뀔 수 있어요

메뉴 이름은 바뀔 수 있고, Pages 무료 조건·공개 범위는 수업 당일 확인합니다.

핵심 3문장

  1. 배포 = 내 파일을 인터넷 주소로 만드는 것. 깃허브는 고정 주소 + 같은 주소 갱신 + 앱 설치가 됩니다.
  2. 파일 이름은 영문 소문자 index.html. 올린 뒤 초록 커밋 단추와 Pages 켜기를 꼭 누르세요.
  3. 개인정보는 올리지 않고, 가입은 전날 집에서, 막히면 플랜 B.
