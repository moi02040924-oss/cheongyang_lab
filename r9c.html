넷리파이(Netlify)로 배포하기 — 다른 방법(선택)

파일을 끌어다 놓으면 인터넷 주소가 생기는 가장 빠른 방법. 수업의 기본 배포는 깃허브입니다.

선택 코너 · 수업 기본은 깃허브(9회차 ②) · 🟦 청양은 구경만 · 강사 임금희

⚠️ 수업 당일 확인 (강사가 먼저 봅니다)

  • 넷리파이 화면·메뉴 이름·무료 한도(월 100GB, 빌드 300분 등)는 강의 자료(2026년 기준)에 적힌 것만 썼고 직접 확인하지 못했습니다. 수업 당일 확인합니다. 화면이 다르면 강사에게 물어보세요.
  • 비교표의 숫자는 자료 작성 시점(2026-09)의 것입니다. 한도는 자주 바뀌므로 가입 시점에 확인합니다.
  • 가입·로그인은 수강생이 직접 합니다. 비밀번호·인증코드는 알려 주지 않고, 결제 창이 뜨면 멈춥니다.
  • 공개 주소로 올리는 순간 누구나 볼 수 있습니다. 개인정보(주민번호·연락처·주소)와 남의 사진·글은 올리지 않습니다.

재배포

  • 코딩이 필요 없어요 — 명령어·프로그램 설치 없이 마우스로 파일만 올립니다.
  • 서버가 필요 없어요 — 복잡한 서버 설정은 넷리파이가 알아서 합니다.
  • 주소가 자동으로 생겨요 — 파일을 올리는 순간 인터넷 주소가 만들어집니다.

넷리파이 따라하기 — 4단계 (선택)

파일 하나를 끌어다 놓으면 내 웹페이지가 인터넷에 올라갑니다. 가입은 내가 직접 합니다.

① 준비하기 — 가입·로그인과 올릴 파일

🔗 오늘 쓰는 사이트
🔗 넷리파이(Netlify) 열기 netlify.com

  1. 인터넷 창 주소창에 netlify.com 을 쓰세요

    열기🔗 넷리파이(Netlify) 열기 netlify.com

    쓰기netlify.com 입니다. (위 링크를 눌러도 됩니다.)

    성공넷리파이 첫 화면이 보이면 성공입니다.

  2. "로그인 / 회원가입"을 누르세요

    누르기처음이면 자동으로 회원가입이 된다고 자료에 있습니다. ※ 단추 이름이 다르면 강사에게 물어보세요.

  3. "Google으로 로그인"을 누르고 평소 쓰는 구글 계정을 고르세요

    보기새 비밀번호를 만들 필요가 없다고 자료에 있습니다. 구글 계정이 없으면 이메일로도 가입된다고 합니다. 비밀번호·인증코드는 다른 사람에게 알려 주지 마세요.

    성공로그인하면 "프로젝트" 화면이 열립니다.

  4. 올릴 HTML 파일을 찾기 쉬운 곳(바탕화면 등)에 두세요

    보기파일 이름은 영문 소문자·공백 없이 권장됩니다(예: my-page.html). 한글·띄어쓰기도 대개 되지만 가끔 말썽을 부린다고 자료에 있습니다.

    성공올릴 파일의 위치를 알고 있으면 성공입니다.

📋 파일 이름 예시 (영문 소문자)
my-page.html

② 배포하기 (핵심) — 끌어다 놓기

  1. "프로젝트" 화면을 여세요

    보기왼쪽 메뉴는 오늘 "프로젝트"만 씁니다. 가운데 점선 큰 상자가 "드롭 존"입니다. 오른쪽 위는 내 계정과 팀 이름입니다.

  2. 파일을 마우스로 누른 채 드롭 존으로 끌고 오세요

    누르기점선 상자 안쪽 위에서 마우스를 놓으세요. 밖에 놓으면 안 됩니다.

    기다리기"배포 중"이라고 뜨고 잠깐 기다리면 끝납니다.

  3. 끌기가 어려우면 버튼으로 올리세요

    누르기"업로드할 파일을 찾아 선택하세요" 단추를 눌러 내 컴퓨터에서 파일을 고르세요. 여러 파일이 든 폴더는 "폴더를 선택하세요"로 올립니다.

    열기🔗 넷리파이 배포 화면(Drop) 열기 app.netlify.com/drop

    보기자료에 app.netlify.com/drop 으로 바로 들어가도 같은 배포 화면이 열린다고 되어 있습니다. 즐겨찾기 해 두면 편해요.

③ 확인하고 공유하기

  1. 배포가 끝나면 나오는 "사이트 카드"를 보세요

    보기넷리파이가 지어 준 영어 주소(예: glowing-…)가 보입니다. 마음에 안 들면 나중에 바꿀 수 있어요.

  2. 초록 "라이브" 표시를 확인하세요

    성공라이브가 떠 있으면 지금 인터넷에 올라가 있다는 뜻입니다. 성공 신호입니다.

  3. 주소를 눌러 열어 보세요

    성공새 창에서 내가 만든 페이지가 뜨면 성공입니다.

  4. 주소를 복사해 카톡 "나에게 보내기"로 먼저 보내 보세요

    성공폰에서 열리면 가족·지인에게 보내도 됩니다. 공개 주소이니 앱에 개인정보가 없는지 먼저 확인하세요.

④ 관리하기 (선택) — 이름 바꾸기 · 재배포 · 삭제

  • ✏️ 사이트 이름 바꾸기 — 어려운 자동 주소를 내가 원하는 이름으로 바꿉니다(예: [원하는-이름]).
  • 🔄 재배포(새 파일 올리기) — 페이지를 고쳤다면 새 파일을 같은 방법으로 끌어다 놓으면 주소는 그대로이고 내용만 바뀝니다. 가장 많이 쓰는 기능입니다.
  • 🗑️ 삭제하기 — 안 쓰는 사이트는 삭제 단추로 지웁니다. 지우면 주소도 사라집니다.
✅ 이것만 기억하세요가장 많이 쓰는 것은 "재배포" — 고친 파일을 다시 끌어다 놓기만 하면 됩니다.

알아 두면 좋은 팁 — 파일 하나일 때, 여러 개일 때

  • 📄 파일이 하나(글자 위주의 간단한 페이지)면 그 파일 하나만 드롭 존에 끌어다 놓으면 됩니다.
  • 🗂️ 사진·여러 파일이면 한 폴더에 모아서 폴더째 올리거나, 폴더를 압축(zip)해서 올립니다. 압축은 폴더를 우클릭 → "압축" → 생긴 zip 파일을 드래그합니다.
  • 💰 개인·실습용은 무료 범위로 넉넉하다고 자료에 있습니다. (무료 한도·정책은 바뀔 수 있어 당일 확인)
🆘 막혔을 때 (눌러서 펼치세요)
❓ 페이지는 떴는데 화면이 텅 비었어요 / 사진이 안 나와요

→ 이미지 파일을 같이 올리지 않았을 때가 많아요. 사진이 든 페이지는 파일 하나만이 아니라 폴더째(또는 압축해서) 올려 주세요.

❓ 주소로 들어가니 파일 목록만 나와요

→ 시작 파일 이름을 index.html로 해 두면 그 페이지가 먼저 열립니다. (여러 파일일 때)

❓ 끌어다 놓기가 안 돼요

→ 파일을 놓는 위치가 점선 상자 안쪽인지 확인하세요. 안 되면 "업로드할 파일을 찾아 선택하세요" 버튼으로 올리세요.

❓ 올려도 되는 내용일까요?

→ 개인정보(주민번호·연락처·주소)와 남의 사진·글은 올리지 마세요. 한번 올리면 누구나 볼 수 있습니다.

❓ 화면이 선생님 것과 달라요

마무리 · 오늘의 흐름과 체크

AI로 만들고 → HTML 파일로 저장하고 → 배포·공유합니다. 수업에서는 이 끝 단계를 깃허브로 합니다.

  1. AI로 웹페이지(앱)를 만들었다

    성공9회차 3교시에서 한 일입니다.

  2. HTML 파일로 저장했다

    성공파일 이름이 영문 소문자이고 index.html 또는 my-page.html 같은 이름입니다. (9회차 ② STEP 2 참고)

  3. (선택) 넷리파이에 끌어다 놓아 주소를 만들었다

    성공라이브 표시와 주소가 있습니다.

  4. 주소를 카톡 나에게 보내 폰에서 열어 봤다

    성공폰에서 열립니다. 수업의 기본은 깃허브(9회차 ②)입니다.
