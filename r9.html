제미나이 캔버스에서 말로 앱 만들기

코드 없이 말로 앱을 만들고, 공유해서 링크와 QR로 나눕니다. '만드는 사람'이 되는 날이에요.

바이브코딩 · 제미나이 캔버스 · 무료 API만 사용 · 키 가입 없이 실습 · 강사 임금희

⚠️ 수업 당일 확인 (강사가 먼저 봅니다)

  • 제미나이에서 캔버스를 켜는 곳, 메뉴 이름, 미리보기 화면, 공유·저장하는 방법, 무료 한도는 이 사이트에 적지 않았습니다. 수업 당일 강사가 확인해서 알려 드립니다.
  • 캔버스 공유는 "스냅샷(그 순간의 사진)"이고, 고쳐도 이미 보낸 링크는 옛 버전이며, 기관 계정은 관리자가 공유를 허용해야 열린다고 강의 자료에 적혀 있습니다. 그날 직접 확인합니다.
  • 실습에 쓰는 API는 무료이고 키가 필요 없는 것만 씁니다. 외부 API 앱이 캔버스에서 되는지도 당일 확인합니다.
  • 오래 쓰는 고정 주소(깃허브 Pages)는 9회차 ② 페이지에, 견본 앱 체험은 ④ 페이지에 따로 정리했습니다. 화면이 다르면 강사에게 물어보세요. 🟦 청양 시니어는 쉬운 부분만, 🟩 홍성 강사반은 선택 코너까지 진행합니다. 결제·카드 입력은 하지 않습니다.

오늘 만들 것

①
말로 만든 앱 1개

제미나이 캔버스에서 인사말 앱 또는 계산기, 설문 앱 중 하나

②
링크와 QR 공유

공유해서 링크를 만들고 QR로 폰에서 열기

집에서 다시 해 보려면

  1. 제미나이(gemini.google.com)에서 캔버스를 열고 "인사말 앱" 요청문을 붙여넣어 앱을 만듭니다. (캔버스 켜는 곳은 수업 때 강사가 알려 준 대로)
  2. 미리보기에서 이름을 써 보고, 고치고 싶은 곳은 "고치기 문구"로 한 가지씩 부탁합니다.
  3. 공유 링크를 만들고, 카톡 "나에게 보내기"로 폰에서 열어 봅니다. 고친 뒤에는 링크를 새로 만드세요.
  4. 링크를 QR로 바꾸는 방법을 AI에게 물어 QR을 만들고, 가족에게 찍어 보게 합니다.
  5. 오래 쓸 것은 개인 지메일 계정으로 만들고, 개인정보가 든 앱은 공유하지 않습니다.
  6. 고정 주소와 앱 설치가 필요하면 9회차 ② 깃허브 배포 페이지를 따라 하세요.

이 페이지 쓰는 법

  1. 수업 중에는 폰이나 컴퓨터에 이 페이지를 열어 두세요.
  2. 각 칸의 누르기 → 쓰기 → 성공 순서로 한 칸씩만 하세요. 끝낸 칸은 "이 단계 했어요"에 체크하면 다음에 열어도 표시가 남습니다.
  3. 검은 상자는 [복사하기]를 누른 뒤 채팅칸에 붙여넣고, 대괄호 [ ] 안만 내 것으로 바꾸세요.
  4. 막히면 🆘 막혔을 때를 눌러 보세요. 화면이 다르면 손을 들어 강사에게 물어보세요.

1교시 · 바이브코딩과 개념 (1~2코너)

오늘은 우리가 직접 "만드는 사람"이 되는 날입니다. 코드를 한 줄도 몰라도 됩니다. 말로 설명하면 AI가 코드를 대신 써 줍니다. 오늘은 제미나이 캔버스에서 웹앱을 만듭니다.

① 바이브코딩 = 코드 없이, 말로 앱 만들기

📖 어려운 말 풀이

바이브코딩
AI에게 "이런 앱 만들어 줘"라고 말로 설명해서 앱이나 웹을 만드는 방법.
제미나이 캔버스
제미나이에서 말로 부탁하면 앱이나 게임 같은 것을 만들 수 있는 작업 공간. 6회차에서 강사가 캔버스로 만든 퀴즈 게임을 구경했습니다. ※ 켜는 곳과 이름은 수업 당일 확인
코드
컴퓨터가 알아듣는 글자 약속. 오늘은 AI가 대신 쓰니 나는 볼 필요가 없습니다.
웹앱
링크를 누르면 열리는 앱. 설치하지 않아도 됩니다.
🔗 오늘 쓰는 사이트
🔗 제미나이(Gemini) 열기 gemini.google.com
  • ① 내가 말로 설명한다 — "이런 앱 만들어 줘"
  • ② AI가 코드를 대신 써 준다 — 나는 코드를 안 봐도 됩니다.
  • ③ 앱이 완성되면 공유한다 — 링크나 QR로 남과 나눕니다.
강사가 이렇게 말해요 — 코드 배운 적 있으세요? 없어도 됩니다. 그게 핵심이에요. 말로 시키면 AI가 만든다, 이 느낌만 가져가면 100점이에요.
✅ 먼저 구경해요수업에서 강사가 "홀랜드 흥미검사 앱"을 보여 줍니다. 코드를 한 줄도 쓰지 않고 말로만 만든 앱인데, 링크나 QR로 폰에서 바로 열립니다. 오늘 여러분도 이런 것을 만듭니다.

② 웹 vs 앱 — 뭐가 다른가요?

  • 웹 = 링크(주소)로 여는 것. 주소만 누르면 열리고, 설치하지 않아도 되며, 카톡으로 링크를 보내면 끝입니다. 오늘 만들 것은 대부분 웹입니다.
  • 앱 = 폰에 설치하는 것. 스토어에서 "설치"를 해야 하고, 폰 홈 화면에 아이콘이 생깁니다. 만들기와 배포가 더 복잡합니다. (웹을 "홈에 추가"하면 앱처럼 쓸 수 있어요.)
💡 카톡으로 링크를 받아서 열어 보신 적 있죠? 그게 웹이에요. 오늘은 링크로 여는 웹을 만듭니다.

③ 어려운 말 4개 — 딱 한 줄씩만

📖 어려운 말 풀이

배포
만든 것을 인터넷에 올려서 "링크"를 만드는 것. (오늘은 이것 하나만 기억하세요: 배포 = 링크 만들기)
서버
내 앱을 24시간 켜 두는 "남의 컴퓨터".
DB(데이터베이스)
입력한 내용을 저장해 두는 "창고".
API
다른 서비스에서 데이터를 받아오는 "창구".
🌱 다 이해하지 않아도 됩니다. "이런 게 있구나" 정도면 오늘 실습은 모두 할 수 있습니다. 🟦 청양은 "배포 = 링크 만들기" 하나만 기억해도 충분해요.

④ API를 "식당"으로 이해하기

  1. 손님 = 내 앱

    보기"미세먼지 알려 줘!" 하고 주문하는 사람입니다.

  2. 종업원 = API

    보기주문을 받아 주방에 전달하고, 결과를 가져옵니다.

  3. 주방 = 다른 서비스

    보기공기질, 날씨 같은 진짜 데이터를 가진 곳입니다.

    성공나는 미세먼지를 재는 법을 몰라도, 종업원(API)에게 부탁만 하면 결과를 받아옵니다.

API는 주로 데이터를 끌어오는 일을 합니다. (가끔 데이터를 보내기도 합니다.)

🆘 막혔을 때 (눌러서 펼치세요)
❓ 웹과 앱이 헷갈려요

→ 링크로 열면 웹, 설치해야 하면 앱입니다. 오늘 만드는 것은 링크로 여는 웹입니다.

❓ API가 너무 어려워요

→ 식당 이야기만 기억하세요. 손님(내 앱) → 종업원(API) → 주방(다른 서비스). 이해 못 해도 실습은 모두 됩니다.

❓ 코드를 모르는데 괜찮을까요?

→ 괜찮습니다. 말로 부탁하면 AI가 대신 씁니다. 코드를 안 봐도 됩니다.

※ 그래도 안 되면 손을 들어 강사에게 물어보세요. 화면이 다르면 강사에게 물어보세요.

2교시 · API 체험과 공유 방법 (3~4코너)

진짜 데이터를 받아오는 앱을 구경하고, 만든 것을 남에게 보여 주는 "공유" 방법을 알아봅니다.

➡ 9회차 ④ 이런 앱을 만들게 돼요 (시연·체험)

① 우리 동네 미세먼지 앱 — 진짜로 받아와요

  1. "청양" 또는 "홍성" 버튼을 누르세요

    누르기강사가 보여 주는 앱(또는 내가 만든 앱)에서 동네 버튼을 누르세요.

  2. 앱이 API에 실시간으로 물어봅니다

    기다리기잠깐 기다리세요. 인터넷이 필요합니다.

  3. 수치와 등급이 뜹니다

    성공지금의 PM2.5(초미세먼지)와 PM10(미세먼지) 수치와 등급이 보이면 성공입니다.

  4. 동네를 바꿔 보세요

    누르기다른 동네 버튼을 누르세요.

    성공수치도 같이 바뀌면 "API로 데이터 받아오기"를 본 것입니다.

강사가 이렇게 말해요 — 제가 미세먼지를 잰 게 아니에요. 앱이 API한테 물어봐서 받아온 거예요. 동네를 바꿔 누르면 수치가 또 바뀌죠? 그때마다 API에 새로 물어보는 거예요.
💡 이 앱은 Open-Meteo 공기질 API를 씁니다. 무료이고 가입이나 키가 필요 없으며, 청양·홍성 좌표가 들어 있습니다. 🟦 청양은 버튼만 눌러 결과를 구경해도 충분합니다.
📋 미세먼지 앱 요청 (무료 API, 키 불필요)
  • 언제 쓰나요? 내가 직접 "우리 동네 미세먼지 앱"을 말로 만들어 보고 싶을 때 (캔버스 입력칸에 붙여넣기)
  • 바꿀 곳 [청양 또는 홍성] 중 하나를 고르거나 내 동네를 쓰세요.
  • 이렇게 나와요 동네 버튼이 있고, 누르면 PM2.5와 PM10 수치와 등급이 큰 글씨로 나오는 화면이 만들어집니다.
[청양 또는 홍성]의 실시간 미세먼지(PM2.5, PM10) 수치와 등급을 보여 주는 웹앱을 만들어 주세요.
무료 공기질 API를 쓰고, 키는 필요 없게 해 주세요.
동네를 고르는 버튼을 두고, 글자는 크게 해 주세요.
⚠️ 인터넷 연결이 필요합니다. 캔버스 미리보기에서 외부 API를 부르는 앱이 되는지는 자료에 없습니다. 수업 당일 확인하고, 안 되면 강사의 시연으로 함께 보세요.
🆘 막혔을 때 (눌러서 펼치세요)
❓ 수치가 안 떠요

→ 인터넷이 연결됐는지 확인하세요. 그래도 안 되면 강사 화면을 같이 보세요.

❓ 캔버스 미리보기에서 막혀요

→ 외부 데이터를 가져오는 앱은 캔버스에서 제한될 수 있는지 확인이 필요합니다. 강사에게 알려 주세요.

※ 그래도 안 되면 손을 들어 강사에게 물어보세요. 화면이 다르면 강사에게 물어보세요.

② 수업에 써먹는 무료 API 모음

  • 🌤️ 날씨 / 😷 미세먼지 — 기온, 강수, PM2.5 등 (Open-Meteo) · 키 불필요
  • 💱 환율 — 달러, 엔 등 오늘 환율 · 키 불필요
  • 📅 공휴일 — 올해 쉬는 날 목록 · 키 불필요
  • 💬 랜덤 명언 — 좋은 글귀 하나씩 · 키 불필요
  • 🐶 동물 사진 — 강아지·고양이 랜덤 사진 · 키 불필요
  • 🔳 QR 생성 — 링크를 QR 이미지로 · 키 불필요
  • 🏛️ 공공데이터포털 — 정부·지자체 각종 데이터 · 키가 필요함 (🟩 홍성 심화)

📖 어려운 말 풀이

키(API 키)
서비스를 쓰는 "열쇠 번호". 가입해서 발급받아야 하는 곳이 있습니다. 오늘은 키가 필요 없는 것만 씁니다.
✅ 🟦 청양은 이렇게"키 불필요" 여섯 가지만으로도 충분히 재미있는 앱이 나옵니다. 키와 가입이 없는 것만 쓰세요.

③ API, 돈 드나요? — 오늘은 0원

  • 무료 API — 0원. 날씨, 미세먼지, 환율 등. 오늘 쓰는 것은 전부 공짜입니다.
  • 유료 API — 쓴 만큼 냅니다. AI, 지도, 문자 발송 등. 대부분 "무료 할당량"이 있습니다.
  • 폰 데이터 — 거의 안 씁니다. 받는 것이 사진이 아니라 글자라서 소모가 미미합니다.
💰 오늘 실습은 무료 API만 씁니다. 유료는 쓴 만큼 돈이 나갈 수 있으니 반드시 요금을 먼저 확인하세요. 카드를 등록하는 서비스는 쓰지 마세요.

④ 공유란? — 만든 것을 남도 볼 수 있게

  • 공유하지 않으면 — 내 화면 안에만 있어요. 나만 볼 수 있고, 링크로 보낼 수 없습니다.
  • 공유하면 — 링크가 생기고, 링크를 받은 사람이 열어 볼 수 있으며, 폰과 QR로 나눠 줄 수 있습니다.
강사가 이렇게 말해요 — 내가 만든 걸 나만 보지 않고 남도 볼 수 있게 링크를 만드는 것이에요. 아까 홀랜드 앱을 링크로 만든 것도 같은 일이었어요.

⑤ 제미나이 캔버스 공유 — 꼭 알아 둘 점 3가지

  1. 캔버스 공유는 "그 순간의 사진(스냅샷)"입니다

    보기"게시" 단추가 없고, 공유하는 순간의 모습이 링크로 만들어집니다.

  2. 고쳐도 이미 보낸 링크는 옛 버전입니다

    쓰기앱을 고친 뒤에는 링크를 새로 만들어 다시 보내세요.

  3. 관리자가 공유를 허용해야 열릴 수 있습니다

    보기학교·기관이 준 계정이면 관리자가 공유를 막아 둘 수 있어요. 링크를 받은 사람이 못 열면 강사에게 알려 주세요.

    성공그래서 캔버스 링크는 "잠깐 보여 주는 임시용"입니다.

캔버스 링크는 임시용입니다. 더 오래, 내 고정 주소로 두고 싶을 때는 9회차 ② 깃허브 배포를 쓰세요(수업에서 하는 배포 방법). 아래는 그 밖의 방법을 이름만 소개합니다. 🟦 청양 시니어반은 구경만 하세요.

➡ 9회차 ② 깃허브로 내 앱 배포하기 (고정 주소 + 앱 설치)

➡ 9회차 ③ 넷리파이로 배포하기 (다른 방법·선택, 비교표)

① 깃허브 말고 다른 배포 방법 한눈에

  • 🥇 구글 사이트(Sites) — 워크스페이스에 이미 있습니다. "게시"를 누르면 진짜 웹 주소가 나오고, 고치면 반영됩니다. 가장 확실합니다. (개인 무료 계정에서도 게시됩니다.)
  • 🟢 Netlify Drop — index.html 파일을 끌어다 놓으면 진짜 웹사이트 주소가 생깁니다. 외부 API 앱도 잘 작동합니다. (따라하기와 깃허브 비교표는 9회차 ③ 선택 페이지에 있습니다.)
  • ⚙️ Apps Script 웹앱 — HTML 앱을 주소로 배포하고 캘린더·시트를 연결할 수 있지만, 설정이 필요한 심화입니다.
  • 🔷 Replit — 서버와 DB까지 다룰 수 있는 가장 전문적인 방법입니다.
🔗 오늘 쓰는 사이트
구글 사이트(Sites) — 주소 확인 필요 (강사가 알려 드립니다)
Netlify — 주소 확인 필요 (강사가 알려 드립니다)
Replit — 주소 확인 필요 (강사가 알려 드립니다)
⚠️ 이 도구들의 화면과 가입·요금은 자료에 없어 적지 않았습니다. 가입이나 결제가 필요하면 강사 안내 없이 진행하지 마세요.

② API로 "AI 기능" 붙이기

  • 내 앱 안에서 AI가 직접 답하게 만들 수 있습니다. 예: 상담 챗봇, 자동 요약 버튼.
  • AI API는 유료지만 무료 할당량이 있는 경우가 많습니다.
  • 키 관리와 요금 확인은 꼭 하세요. 카드를 등록하는 API는 사용량 알림을 설정하는 것이 좋습니다.

③ DB(저장) 맛보기

  • 설문이나 명단을 "저장"해 둘 수 있습니다.
  • 구글 시트를 간이 DB로 쓰는 것이 가장 쉬운 시작입니다. 수강생 응답을 시트에 자동 저장하는 실습으로 넓힐 수 있습니다.
  • Apps Script나 Replit으로 연결합니다.
  • 개인정보는 최소한만 받고, 저장·공유 전에 동의와 보관 방법을 정하세요.

마무리 · 나도 이제 "만드는 사람"

오늘 배운 것 세 가지를 소리 내어 읽어 보세요.

  • ① 말로 시키면 AI가 앱을 만든다.
  • ② API로 다른 곳의 데이터를 받아온다.
  • ③ 공유하면 링크와 QR로 남과 나눈다.
강사가 이렇게 말해요 — 만들고, 공유하고, 나누는 것. 여기까지 하면 여러분은 이제 그냥 쓰기만 하는 사람이 아니라 만드는 사람이에요. 오늘 만든 앱, 집에 가서 하나 더 만들어 보세요.

오늘의 미션 · 마지막 점검

아래 칸을 눌러 표시하며 오늘 한 일을 확인해 보세요.

  1. 캔버스에서 앱을 말로 만들었다

    성공미리보기에서 내 앱이 보입니다.

  2. 고칠 곳을 말로 한 번 고쳐 봤다

    성공"더 크게"처럼 말하면 앱이 바뀌는 것을 봤습니다.

  3. 공유해서 링크를 만들었다

    성공주소(링크)가 있고, 카톡 나에게 보내기로 폰에서 열렸습니다.

  4. 링크를 QR로 만들어 폰으로 열었다

    성공폰 카메라로 QR을 찍으면 앱이 열립니다.

  5. 옆 사람과 서로의 앱을 열어 봤다

    성공"남과 나누기"를 해 봤습니다. 박수!

청양(시니어) 목표: 링크와 QR까지 나오면 오늘 목표 달성입니다. 홍성(강사) 목표: 다음 강의에서 쓸 앱 하나 완성하기(과제).

주의 사항

⚠️ 화면은 자주 바뀌어요

제미나이 캔버스의 메뉴와 화면은 업데이트로 달라집니다. 당일 화면 기준으로 확인하세요.

⚠️ 캔버스 링크는 임시용이에요

스냅샷이라 고쳐도 옛 링크는 옛 버전이고, 관리자가 공유를 허용해야 열릴 수 있습니다. 고친 뒤에는 링크를 새로 만드세요.

⚠️ 무료 API만 쓰세요

키가 필요 없거나 무료 할당량이 있는 API만 씁니다. 유료 API는 쓴 만큼 돈이 나갈 수 있으니 요금을 먼저 확인하세요.

⚠️ 계정 보관

오래 쓸 것은 개인 지메일 계정으로 만드세요. 계정이 사라지면 그 안의 것도 함께 사라집니다. 만료 전 Google Takeout으로 백업합니다.

⚠️ 개인정보는 최소한으로

설문이나 명단을 받는 앱은 꼭 필요한 것만 받고, 이름·연락처·주민번호는 묻지 마세요. 개인정보가 든 앱은 아무에게나 공유하지 마세요.

핵심 3문장

  1. 말로 시키면 AI가 앱을 만들어 줍니다.
  2. API로 데이터를 가져오고, 키가 필요 없는 무료 API부터 쓰세요.
  3. 공유하면 링크와 QR로 나눌 수 있어요.

"만들고 → 공유하고 → 남과 나눈다"
